E65WEB STUDIO WEBSITE: UPLOAD GUIDE

WHAT IS IN THIS FOLDER
index.html   The whole website (all pages are inside it)
assets/      Logo and project screenshots
robots.txt   Lets search engines visit the site
.htaccess    Optional speed settings for Apache hosting

HOW TO UPLOAD (cPanel)
1. Log in to your hosting control panel and open File Manager.
2. Open the public_html folder (or the folder of your domain).
3. Upload the contents of this folder: index.html, the assets folder, robots.txt and .htaccess.
   Keep the assets folder next to index.html.
4. Visit your domain. The home page should appear.
5. Turn on the free SSL certificate in your host (often called AutoSSL or Let's Encrypt).

TEST THE FORM
1. Open your live domain and go to Start a Project.
2. Fill in the questionnaire and press Send brief.
3. Check the inbox you registered with Web3Forms, and the spam folder.
4. In your Web3Forms dashboard you can limit the access key to your domain to reduce spam.

EDITING LATER
Page text lives inside index.html. Ask Claude to make changes and re-upload the file.

KNOWN LIMITS
Pages use address links such as /#services. They work on any host, but search engines treat the site as one page. Ask for a version with separate page addresses when you are ready for stronger SEO.
